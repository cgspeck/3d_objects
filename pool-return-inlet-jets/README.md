# Pool Return Inlet Jet

Two designs:

1. One that uses a snorkel and the venturi effect to draw in air and aerate pool water.
1. As above but when the snorkel is removed it will draw in and accelerate pool water

## Getting started

1. Follow instructions on [Threadlib to install](https://github.com/adrianschlatter/threadlib?tab=readme-ov-file#installation) it and its dependencies.

2. Install BSOL2

## Thread sizes tried

1 1/2" BSPP

```nut("G1 1/2", turns=4, Douter=60, nut_sides=6);```

- too small

Unified National Course 2"
"UNC-2" 

- thread pitch too large

"6-UN-2-ext"
- thread pitch too large
